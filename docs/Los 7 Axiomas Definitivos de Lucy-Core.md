### Los 7 Axiomas Definitivos de Lucy-Core

Para que tu proyecto "Semilla" sea una joya de ingeniería, el stack se cierra así:

1. **TailwindCSS v4:** Estética.

2. **Vue 3 (Composition):** Reactividad.

3. **Vite 7 (Library Mode):** Empaquetado profesional.

4. **Shadcn/Reka:** Base de accesibilidad.

5. **PrimeVue (Unstyled):** Componentes complejos.

6. **TypeScript:** Contrato de datos y seguridad.

7. **Zod (Axioma extra):** Para esquemas de validación. Si defines cómo es un "Alumno" en la librería con Zod, tanto el Front como el Back (vía interfaces) hablarán el mismo idioma.
