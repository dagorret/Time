# 📑 Manual de Comandos Time

### Gestión del Entorno
- `docker compose up -d`: Enciende los motores en segundo plano.
- `docker compose down`: Apaga la fábrica.
- `docker compose ps`: Revisa si el contenedor está corriendo.

### Desarrollo y Construcción
- `npm run dev`: Inicia el modo "Showroom" (localhost:5173).
- `npm run build`: Ejecuta la fábrica y genera la carpeta `dist/`.
- `npm run preview`: Prueba la librería ya construida.
- `npm install`: Instala nuevas dependencias dentro del entorno.
